# Python Data Exploration and Cleaning

## About

This project was created to practice **data exploration** and **data cleaning** using **Python**, **Pandas**, and **NumPy**. It focuses on identifying common data quality issues and applying cleaning techniques to prepare datasets for analysis.

The project includes two datasets:

- student_dirty_dataset
- sales_dirty_dataset

## Project Structure

```
Python_Data_Cleaning/
│
├── student.py
├── student_analysis.py
├── sales.py
├── sales_analysis.py
├── student_dirty_dataset.csv
├── sales_dirty_dataset.csv
├── student_cleaned_dataset.csv
└── sales_cleaned_dataset.csv
```

## Project Tasks

For each dataset, I:

- Explored the dataset to understand its structure
- Identified missing values and duplicate records
- Detected invalid or inconsistent data
- Cleaned and standardized text fields
- Corrected numeric values using appropriate methods
- Validated the cleaned data
- Exported the cleaned dataset as a new CSV file

## Technologies

- Python
- Pandas
- NumPy

## Output Files

The cleaning scripts generate the following files:

- `student_cleaned_dataset.csv`
- `sales_cleaned_dataset.csv`

## Purpose

This project helped me strengthen my understanding of data preprocessing, one of the most important steps in any data analysis or machine learning workflow. It also provided hands-on experience with using Pandas to clean and prepare real-world datasets.
